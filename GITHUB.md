# Pushing ThermaMorph to GitHub

Follow these steps exactly. The challenge requires a **public** repository on a **single `main` branch** with a maximum of **3 submissions**.

---

## 1. Create a GitHub repository

1. Go to https://github.com/new
2. Repository name: `thermamorph`
3. Set visibility to **Public** ✓
4. **Do NOT** initialise with README, .gitignore, or licence — the project already has these
5. Click **Create repository**
6. Copy the repository URL shown (e.g. `https://github.com/YOUR_USERNAME/thermamorph.git`)

---

## 2. Initialise git and push

Open a terminal in the project folder, then run these commands one at a time:

```bash
# Move into the project folder (skip if you're already there)
cd path/to/thermamorph

# Initialise git
git init

# Set the default branch to main
git branch -M main

# Stage all files
git add .

# First commit
git commit -m "feat: initial ThermaMorph submission"

# Connect to your GitHub repository
git remote add origin https://github.com/YOUR_USERNAME/thermamorph.git

# Push
git push -u origin main
```

Replace `YOUR_USERNAME` with your actual GitHub username.

---

## 3. Verify what was pushed

After pushing, open your repository on GitHub and confirm:

- [ ] `README.md` is visible and shows the ThermaMorph content (not the default Next.js boilerplate)
- [ ] `.env.local.example` is present (it is no longer blocked by .gitignore)
- [ ] `__tests__/validators.test.ts` and `__tests__/energy-engine.test.ts` are present
- [ ] `lib/analysis/energy-engine.ts` is present
- [ ] `supabase/migrations/` folder is present
- [ ] `.env.local` is **not** present (it contains your real keys)

---

## 4. What is NOT pushed (by design)

These are excluded by `.gitignore` and should never be committed:

| File | Why |
|---|---|
| `.env.local` | Contains your real Supabase keys |
| `node_modules/` | Large, regenerated by `npm install` |
| `.next/` | Build output |
| `*.tsbuildinfo` | TypeScript incremental build cache |

---

## 5. If you need to make a fix before submitting

```bash
# Make your changes, then:
git add .
git commit -m "fix: <describe what you fixed>"
git push
```

> ⚠️  **Remember: you have a maximum of 3 submissions.** Push all your changes in one go before you submit the challenge URL. Do not submit until the repo is in its final state.

---

## 6. Submit the repository

When ready, submit `https://github.com/YOUR_USERNAME/thermamorph` through the challenge portal. The judges will:

1. Clone the repo
2. Read `README.md`
3. Run `npm install` then `npm run dev` following `SETUP.md`
4. Run `npm test` to verify tests pass
5. Evaluate against the rubric

---

## Common issues

| Problem | Fix |
|---|---|
| `git push` fails with "remote already exists" | `git remote set-url origin https://github.com/YOUR_USERNAME/thermamorph.git` |
| `.env.local.example` not showing on GitHub | Run `git add .env.local.example` then commit again |
| Push rejected (non-fast-forward) | `git pull --rebase origin main` then `git push` |
| File shows as modified but you don't want to commit it | `git checkout -- <filename>` |
